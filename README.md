# EzAuto

External autobunnyhop for GoldSrc and Source engine games.

Check the [Releases tab for latest version](https://github.com/TotallyMehis/EzAuto/releases).

## Building

- Install [Visual Studio](https://visualstudio.microsoft.com/). Choose the `Desktop development with C++` workload. You also need **CMake** support.
- Within `Developer Powershell for VS 20XX` shell (found in start menu or by searching), run CMake: `cmake -B build`
- Open solution `build/ezauto.sln` and build with `RelWithDebInfo` configuration. You now have `ezauto.exe` in `ezauto`-directory.
